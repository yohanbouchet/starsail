Projet 7 du Master Expert DevOps d'OpenClassrooms : « Analysez une
infrastructure et un stack technique et définissez des nouvelles
solutions ». Projet **documentaire** : aucun code applicatif.

## Contexte

StarSail Inc. (entreprise fictive, une trentaine de personnes) développe
**StarMap**, une application web et mobile qui détermine la position de
l'utilisateur à partir d'une photo du ciel nocturne (PHP 8 / Symfony,
TypeScript / Stimulus, PostgreSQL, Docker, Ansible). Les livraisons sont
manuelles et les échanges entre développeurs et exploitants passent par
e-mail. La mission : auditer la chaîne CI/CD actuelle, mener une veille
technologique, puis spécifier un pipeline modernisé.
